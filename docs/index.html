Get started in three steps

  1. Download Flixdex.exe and run it. If Windows shows "Windows protected your PC", click More info → Run anyway (the app isn't code-signed).
  2. Get a free TMDB API key at themoviedb.org/settings/api. For the application URL, http://localhost is fine.
  3. Paste the key into Flixdex and pick your country. The first start takes a few minutes; after that it opens instantly.

Questions

Is Flixdex free?

Yes, free and open source (MIT license). You only need a free TMDB API key.

Do I need a Netflix or HBO Max account?

Not to browse. The Watch button opens the title on the service's website, where you need your own subscription to play it.

Which countries work?

Any country where TMDB and JustWatch track Netflix or HBO Max, which is most of them. Choose yours in Settings.

Where do the ratings come from?

IMDb ratings come from IMDb's official ratings dataset, downloaded once a day. The catalog comes from TMDB, with streaming availability by JustWatch.

Is there a Mac or phone version?

Not yet. Flixdex is Windows-only for now. The source is on GitHub.
